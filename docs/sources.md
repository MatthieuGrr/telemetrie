# Sources suivies

Chaque matin, la veille parcourt les nouveautés des dernières 24 à 48 heures sur les sources
ci-dessous, en retient quelques-unes et les résume avec le lien vers l'article d'origine.
Des recherches web ciblées complètent la collecte : les blogs, labos et annonces cités
ponctuellement sur le site en viennent, sans être suivis en continu.

## Chaque jour

- [arXiv cs.RO](https://arxiv.org/list/cs.RO/recent) — prépublications en robotique ([flux RSS](https://rss.arxiv.org/rss/cs.RO))
- [ROS Discourse](https://discourse.openrobotics.org/) — communauté ROS 2 : nouveaux paquets, sorties, distributions
- [CNX Software](https://www.cnx-software.com/) — cartes embarquées, SoC, microcontrôleurs, ordinateurs monocartes
- [The Robot Report](https://www.therobotreport.com/) — actualité de l'industrie robotique

## Sorties de logiciels

Suivies par leurs flux de versions GitHub :

- [Nav2](https://github.com/ros-navigation/navigation2/releases) — navigation ROS 2
- [ESP-IDF](https://github.com/espressif/esp-idf/releases) — SDK des ESP32
- [Pico SDK](https://github.com/raspberrypi/pico-sdk/releases) — SDK des RP2040 / RP2350
- [Pixi](https://github.com/prefix-dev/pixi/releases) — gestion d'environnements et de dépendances
- [Zenoh](https://github.com/eclipse-zenoh/zenoh/releases) et [rmw_zenoh](https://github.com/ros2/rmw_zenoh/releases) — middleware, alternative à DDS pour ROS 2
- [balenaOS](https://github.com/balena-os/meta-balena/releases) et [Mender](https://github.com/mendersoftware/mender/releases) — systèmes et mises à jour OTA pour flottes embarquées

- [Foxglove](https://foxglove.dev/blog) — visualisation et enregistrement de données robotiques

- [balena](https://blog.balena.io/)
- [Tailscale](https://tailscale.com/blog)

- Blogs d'ingénierie d'entreprises robotiques : Dexory, Starship, Zipline, Locus Robotics, Clearpath / OTTO Motors
