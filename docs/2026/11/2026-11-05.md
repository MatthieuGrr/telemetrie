# Veille du jeudi 5 novembre 2026

## Mbed TLS pourrait perdre ses mainteneurs

Les mainteneurs actuels arrêtent les parties TLS et X.509 en avril 2027 : sans relève d'ici là, il n'y aura plus de correctifs de sécurité. La partie crypto (TF-PSA-Crypto) reste maintenue. ESP-IDF s'appuie sur Mbed TLS ; l'annonce date d'environ un mois mais vient de remonter sur Hacker News.

[Source : lists.trustedfirmware.org](https://lists.trustedfirmware.org/archives/list/mbed-tls@lists.trustedfirmware.org/thread/YPIGCB7WN6GCHOGEGKOJXUYAP7OK527W/)
{ .source-link }

## Failles Linux : 948 exploits générés par IA

OpenAI a fait tourner un pipeline d'agents sur le noyau : 2 308 failles candidates, 1 724 reproduites et 948 exploits donnant le root à un utilisateur local, pour environ 1,2 M$ (soit environ 360 $ par exploit). Des humains relisent avant de signaler les failles aux mainteneurs. Ces chiffres viennent d'OpenAI, et les correctifs sont encore en cours.

[Source : openai.com](https://openai.com/index/a-thousand-fewer-paths-to-root/)
{ .source-link }

## Même tendance côté robotique

VicOne, éditeur de sécurité, annonce 28 zero-days trouvés en moins de deux jours avec l'aide de l'IA, dans des outils de l'écosystème robotique. 75 % touchent l'entraînement, la simulation ou la validation, pas le robot lui-même. Le décompte reste à confirmer.

[Source : therobotreport.com](https://www.therobotreport.com/28-zero-day-findings-in-less-than-two-days-what-ai-speed-discovery-means-for-robotics/)
{ .source-link }

## cuRoboV2-Fast : planification de mouvement en 4,4 ms

NVIDIA publie un planificateur sur GPU qui évite les collisions et respecte les limites de couple en tenant compte de la charge portée. Il est 14,7 fois plus rapide que cuRoboV2 sur RTX 5090, et plus rapide sur Jetson AGX Orin que l'ancienne combinaison cuRoboV1 + TOPPRA sur RTX 5090. Le code est sous Apache 2.0.

[Source : arxiv.org](https://arxiv.org/abs/2611.06913v1)
{ .source-link }

## Tactile : ce qui aide vraiment un robot à manipuler

Une étude sur 720 essais réels, avec la plateforme LeRobot, fait passer le taux de réussite de 57,8 % à 78,9 % grâce au toucher. Le meilleur signal isolé est le flux de marqueurs (74,4 %) : on suit des points sur la peau souple du capteur pour voir comment elle se déforme (glissement, cisaillement).

[Source : arxiv.org](https://arxiv.org/abs/2611.06673v1)
{ .source-link }

## Nordic nRF71 : du Wi-Fi 6 pour le fonctionnement sur batterie

Nordic annonce une veille Wi-Fi 20 fois plus sobre que la série nRF70 (chiffre constructeur). Le nRF7120 combine un Cortex-M33 à 256 MHz, 1 Mo de RAM, 4 Mo de mémoire non volatile, Wi-Fi 6, BLE et Thread. Un coprocesseur RISC-V émule des périphériques comme le CAN 2.0B en logiciel.

[Source : cnx-software.com](https://www.cnx-software.com/2026/11/03/nordic-semi-nrf71-wireless-chips-to-deliver-20-times-lower-standby-power-for-battery-operated-wifi-devices/)
{ .source-link }

## 💡 Concept du jour : la paramétrisation temporelle

On sépare deux questions : par où passer (le chemin), puis à quelle vitesse le parcourir. Une fois le chemin fixé, il ne reste qu'à trouver la vitesse maximale à chaque point sans dépasser les limites de vitesse, d'accélération, de jerk et de couple. C'est le rôle de TOPPRA et du module TimeOpt de cuRoboV2-Fast, et c'est ce qui raccourcit le cycle sans toucher à la trajectoire.
