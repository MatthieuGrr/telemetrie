# Veille du vendredi 6 novembre 2026

## VLA-Tug : savoir qu'un robot va rater son geste avant qu'il le rate

Une petite sonde lit les couches internes d'un modèle VLA (vision-langage-action) et prévient d'un échec avant qu'il arrive. Elle donne aussi le type d'échec, ses taux d'erreur restent sous une limite fixée à l'avance, et elle est assez légère pour tourner sur le robot lui-même. Le code et 3 180 épisodes annotés sont publiés.

[Source : arxiv.org](https://arxiv.org/abs/2611.08425)
{ .source-link }

## Recaler une flotte de robots grâce au Wi-Fi

En localisation coopérative, les robots se mesurent les uns par rapport aux autres : toute l'équipe peut donc dériver ensemble sans s'en rendre compte, c'est la « dérive de jauge ». Le papier corrige ça avec une carte de la puissance radio reçue, calée dans le même repère que la carte du monde.

[Source : arxiv.org](https://arxiv.org/abs/2611.08361)
{ .source-link }

## VisionSIM : un simulateur qui reproduit les défauts des capteurs

Les simulateurs courants donnent des capteurs parfaits. VisionSIM reproduit leurs vrais défauts : éblouissement du LiDAR, repliement de phase des caméras ToF, événements perdus sur une caméra événementielle, inertie d'une caméra thermique.

[Source : arxiv.org](https://arxiv.org/abs/2611.08368)
{ .source-link }

## Olimex UEXT-CH390 : de l'Ethernet filaire en SPI

Un petit module matériel open source à base de WCH CH390 (10/100 Mbit/s). Il ajoute un port RJ45 aux Pico/Pico 2 et aux ESP32-S3/C3/C6, compatible ESPHome.

[Source : cnx-software.com](https://www.cnx-software.com/2026/11/06/olimex-uext-ch390-spi-to-ethernet-module-targets-raspberry-pi-and-esp32-mcu-boards-running-esphome/)
{ .source-link }

## P4 Launcher : des applis sans reflasher l'ESP32-P4

Un bureau façon PC pour ESP32-P4 avec écran tactile. Les applis sont des fichiers .papp rangés sur microSD et chargés en PSRAM au lancement, sans reflasher le firmware : un exemple rare de chargement dynamique de code sur microcontrôleur.

[Source : cnx-software.com](https://www.cnx-software.com/2026/11/05/p4-launcher-offers-a-pc-like-and-retro-gaming-experience-on-esp32-p4-boards/)
{ .source-link }

## Thinking Machines sort Inkling 2 Small

Un modèle MoE de 594 milliards de paramètres, dont 17 milliards actifs, qui accepte des images. Les poids seront publiés sous Apache 2.0 la semaine suivante, après des tests de sécurité externes.

[Source : thinkingmachines.ai](https://thinkingmachines.ai/news/inkling-2-small/)
{ .source-link }

## 💡 Concept du jour : le Bluetooth Channel Sounding

NXP l'intègre à ses nouveaux MCU MCX W70 et KW43. Pour mesurer une distance, le RSSI (force du signal) est très imprécis : le Channel Sounding (Bluetooth 6) mesure plutôt le **déphasage** du signal sur plusieurs fréquences, et chronomètre l'aller-retour. On obtient une distance à quelques dizaines de centimètres près, difficile à falsifier, d'où son usage pour les clés de voiture.

[Source : cnx-software.com](https://www.cnx-software.com/2026/11/05/nxp-mcx-w70-and-kw43-wireless-mcus-support-bluetooth-channel-sounding-for-iot-and-automotive-applications/)
{ .source-link }
