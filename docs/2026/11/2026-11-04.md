# Veille du mercredi 4 novembre 2026

## Stringman : un robot grand comme la pièce, avec 4 moteurs

Une pince suspendue à 4 câbles ancrés aux coins du plafond (open source, certifié OSHWA : CAD, PCB, code). Environ 1,9 kg de charge moyenne, contre 0,32 kg pour un bras 7 axes de 0,75 m avec les mêmes actionneurs, selon le fabricant, pour une vitesse d'environ 0,4 m/s. La charge est limitée par une tension de 28 N par câble.

[Source : neufangled.com](https://neufangled.com/)
{ .source-link }

## ISO 21423:2026 : un langage commun pour les robots mobiles

Cette nouvelle norme définit comment AGV, AMR et gestionnaires de flotte de marques différentes échangent position, vitesse, état et tâches. Elle couvre aussi les ascenseurs, les portes et l'ERP. L'article ne dit rien du lien avec VDA 5050, le protocole déjà répandu.

[Source : therobotreport.com](https://www.therobotreport.com/new-iso-interoperability-standard-covers-collaboration-among-mobile-robots-from-multiple-vendors/)
{ .source-link }

## Rooter son GPS Renault pour changer l'heure

Sur ce TomTom sous Linux 2.6, le menu de réglage de l'heure est défini sur la carte SD de navigation, protégée par DRM. L'auteur enchaîne une écriture de fichier par path traversal et un crash volontaire pour exécuter son script en root, via l'astuce `core_pattern` (le noyau lance lui-même un script quand un processus plante). Au final, il passe un décalage de 180 à 120 minutes.

[Source : blog.nns.ee](https://blog.nns.ee/2026/11/02/renault-hack/)
{ .source-link }

## PadLoc : se localiser sur un plan, sans entraînement

Ce back-end place un capteur sur un plan d'étage en s'appuyant sur l'orientation des murs, la corrélation de l'espace libre et un filtre bayésien. Avec LiDAR et odométrie roues, il atteint 9-10 cm d'erreur médiane sur la séquence statique (résultats annoncés par les auteurs), et l'état reste compact quelle que soit la longueur du trajet.

[Source : arxiv.org](https://arxiv.org/abs/2611.05172v1)
{ .source-link }

## DataFarm : un agent IA à la place du téléopérateur

Un agent de code recrée la tâche en simulation, puis un modèle vidéo rend les épisodes de façon photoréaliste. Sur 5 tâches réelles : 93 réussites sur 100 contre 84 en téléopération, et 87 contre 46 sous conditions visuelles inédites. Le coût est d'environ 107 $ de l'heure de données, à peine moins que les 117 $ d'un devis de téléopération en Chine.

[Source : arxiv.org](https://arxiv.org/abs/2611.05320v1)
{ .source-link }

## Correctif : les réseaux « lus à l'œil nu » par GPT-6 Astra

Le billet sur la « weight-space programming » (veille du 3 novembre) mélange plusieurs techniques : la lecture directe des poids ne concerne que 3 expériences, sur 17K à 172K poids. Le gain spectaculaire sur Qwen passe par du Python et 50 exécutions du réseau, et la même méthode échoue sur Gemma 3. Simon Willison reproduit tout de même un des exemples en local avec Qwen 3.8.

[Source : honnibal.dev](https://honnibal.dev/blog/astra-read-write-misleading) · [Source 2 : simonwillison.net](https://simonwillison.net/2026/Nov/3/qwen-can-interpret-model-weights/)
