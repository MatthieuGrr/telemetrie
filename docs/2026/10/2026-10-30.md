# Veille du vendredi 30 octobre 2026

## Un « world model » qui tourne sur un Pico 2 W 🎮

Deux petits réseaux tournent ensemble sur le core 1 d'un RP2350 : le premier prédit l'image suivante à partir de l'image courante et d'une action, le second joue dans ce « rêve ». C'est fait pour Breakout, Pong, Flappy, un Doom-lite et un Pac-Man lite, avec 26k à 131k paramètres en int8 et 2 à 8 millions de multiplications par image. Pendant ce temps, le core 0 gère l'USB et l'écran ; le README est très pédagogique.

[Source : github.com](https://github.com/SheepSeb/tinyworldformer)
{ .source-link }

## Un tutoriel sur le contrôle de la forme des objets déformables

Le but : piloter des bras pour donner à un câble ou une tige souple la forme voulue, en boucle fermée avec une caméra, sans modèle mécanique précis de l'objet. Le papier, une approche d'automatique classique (Jacobien, stabilité), est accompagné de code et de démos interactives.

[Source : arxiv.org](https://arxiv.org/abs/2610.40559)
{ .source-link }

## SwapBot : changer d'outil et ajouter le toucher

Des adaptateurs bon marché transforment des ustensiles de cuisine en outils de robot, montés sur un raccord commun et équipés de capteurs tactiles. Avec le toucher, les politiques apprises par imitation réussissent 15 à 25 points de plus qu'avec la caméra seule.

[Source : arxiv.org](https://arxiv.org/abs/2610.40646)
{ .source-link }

## Gym-Anything : des IA de code qui écrivent des simulateurs de robots

Des agents de code génèrent 25 simulations de tâches physiques « utiles », vérifiées par une boucle où un agent crée et un autre contrôle. Même les meilleurs modèles actuels échouent sur toutes les tâches de test (score moyen 0,06).

[Source : arxiv.org](https://arxiv.org/abs/2610.40565)
{ .source-link }

## Mistral publie les poids de Large 4 🇫🇷

C'est un modèle d'un trillion de paramètres entraîné en Europe. Mistral dit qu'il est le meilleur modèle ouvert en code (Terminal-Bench 41 %) et qu'il consomme moins de tokens. Le sujet a été très discuté sur Hacker News.

[Source : mistral.ai](https://mistral.ai/news/mistral-large-4-oss/)
{ .source-link }

## 💡 Concept du jour : le Jacobien de déformation

C'est un tableau de sensibilités qui dit : « si la pince bouge de 1 mm dans cette direction, de combien bouge chaque point de la forme ? ». Au lieu de le calculer avec un modèle physique, on le mesure en faisant de petits mouvements et on le corrige en continu. Le contrôleur l'« inverse » ensuite pour savoir comment bouger afin de réduire l'écart avec la forme visée, comme dans le contrôle visuel d'un bras par caméra.
